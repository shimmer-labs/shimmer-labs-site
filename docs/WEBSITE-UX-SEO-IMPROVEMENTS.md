# Shimmer Labs Website - UX, SEO & Marketability Improvements

**Date:** November 21, 2025
**Analyzed:** shimmerlabs.co vs ottomate.co (reference site)
**Goal:** Add service packages, improve conversion, enhance SEO

---

## Executive Summary

Your site is clean and professional, but it's missing **the money**. You're showcasing projects without clear packages, pricing, or conversion paths. Ottomate.co nails this with bold offerings, clear CTAs, and trust signals everywhere.

**Big wins to implement:**
1. **Add pricing packages to homepage** (like Ottomate's Consulting/Training split)
2. **Create dedicated /services page** with actual packages & pricing
3. **Add social proof** (testimonials, case studies, video if possible)
4. **Improve SEO** (missing title tags, meta descriptions, schema markup)
5. **Sharpen the value prop** (what you do, who for, how much)

**Meta Descriptions (Missing on Most Pages)**

```html
<!-- Homepage -->
<meta name="description" content="Custom app development for $18k-55k in 3-6 weeks. Next.js, Supabase, Stripe, iOS. Built Paidly (SaaS) & EventSnag (iOS). Based in Stillwater, OK.">

<!-- Services -->

<!-- Projects -->
<meta name="description" content="Portfolio: Paidly (AI invoicing SaaS), EventSnag (iOS app), 4 podcast API integrations, TreeBidPro (Figma to production). Real shipped products.">
```

**Schema Markup (Add to `<head>`)**

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "ProfessionalService",
  "name": "Shimmer Labs",
  "description": "Custom app development and automation consulting",
  "founder": {
    "@type": "Person",
    "name": "Logan Shimmer",
    "jobTitle": "Founder & Automation Architect"
  },
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "Stillwater",
    "addressRegion": "OK",
    "addressCountry": "US"
  },
  "priceRange": "$$$",
  "url": "https://shimmerlabs.co",
  "sameAs": [
    "https://www.linkedin.com/in/loganshimmer/",
    "https://github.com/shimmer-labs"
  ]
}
</script>
```

**Why:**
- Better Google search previews
- Rich snippets (can show pricing, reviews)
- Local SEO benefit (Stillwater, OK)

## Brand Voice Guidelines (From Logan's Tone)

**Do:**
- Be informal ("Stop doing the same shit every day")
- Use specifics ("$35k in 6 weeks" not "affordable and fast")
- Show receipts ("Built Paidly 0→1 in 6 weeks, processing payments")
- No buzzwords ("synergize", "leverage", "solutions", "innovative")
- Use emojis sparingly for personality (🔌 ⚡ 🔗)

**Don't:**
- Corporate speak ("We provide end-to-end solutions...")
- Vague promises ("Best in class", "World-class")
- Passive voice ("Services are offered")
- Over-selling ("Revolutionary!", "Game-changing!")

**Examples:**

❌ "We leverage cutting-edge technologies to deliver innovative solutions"
✅ "I build with Next.js, Supabase, and Stripe. No janky workarounds."

❌ "Our streamlined process ensures maximum efficiency"
✅ "3 steps: We talk, I build, you launch. Done in 6 weeks."

❌ "Contact us for a customized quote"
✅ "Here's what I charge. No surprises."

## Analytics & Tracking

**Add event tracking:**
```javascript

trackEvent('cta_click', {
  location: 'homepage_hero',
  text: 'See Pricing & Book Consultation'
});

// Track pricing page views
trackEvent('page_view', {
  page: '/services',
  package_interest: 'wireframe_to_web_app'

// Track Calendly bookings

  source: 'homepage',
```
