The Build

Three files make it yours.

The brand guide and the audit Kristen had you build this morning? That’s context. It goes in a file. A .md is a text file with headings. Don’t get hung up on it.
File 1
writing-style.md

Your writing style

How you actually sound. Pulled from emails you already wrote, then corrected by you.

Without it: every draft sounds like a press release.
File 2
mission-control.md

Mission control

Which emails it drafts, which stay human, which it ignores. A table you flip rows on as you get confident.

Without it: it drafts a reply to the angry one.
File 3
reference.md

Reference

Policies, hours, prices, the lease, the FAQ. Whatever you’d look up before answering.

Without it: it makes the policy up.
Generic AI writes generic email. These three files are the difference.
