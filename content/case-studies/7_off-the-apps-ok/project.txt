## The Challenge
Stillwater needed a way to discover local events without relying on dating apps. People wanted authentic, in-person connections.

## The Solution
Built a content system that curates and publishes local events:
- Collects event data from multiple sources around Stillwater
- OCR extracts text from event flyers
- AI curates, categorizes, and writes engaging captions
- Auto-generates branded Instagram posts
- Publishes 2x weekly without manual intervention

## The Tech
A custom pipeline connecting event discovery to Instagram publishing:
1. Event flyers come in via Telegram
2. OCR extracts details from images
3. Google Sheets stores and deduplicates events
4. AI writes engaging captions matching the account's voice
5. Canva API creates branded graphics
6. Instagram API publishes automatically

----
Results: Curates 20+ events weekly, automates content creation, and supports a growing community of local explorers in Stillwater, OK looking to connect Off The Apps.
